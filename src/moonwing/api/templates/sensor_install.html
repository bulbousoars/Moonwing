Treat the enrollment token like a bootstrap secret: anyone who has it can register a sensor against this manager. Rotate it by changing MOONWING_SENSOR_ENROLLMENT_TOKEN and restarting the API. Use one canonical manager URL for every user and endpoint (HTTPS + DNS strongly recommended).

linux Linux endpoint

Bash installer for systemd-based Linux. Enrolls the host, drops a heartbeat agent under /opt/moonwing-sensor, and registers moonwing-sensor.service.

Requirements: root, curl, python3, systemd.

Download installer

Interactive / browser — this URL requires a logged-in session. For fleet rollout use deploy/sensors/install-sensor.sh with MOONWING_MANAGER_URL + MOONWING_ENROLLMENT_TOKEN copied from above.

One-liner (same login as this page) 
curl -fsSL '{{ manager_url }}/sensors/install/linux.sh' | sudo bash

windows Windows endpoint

PowerShell installer for Windows 10/11 and Server. Enrolls the host, drops the heartbeat agent under C:\ProgramData\Moonwing\sensor, and registers a SYSTEM-context scheduled task.

Requirements: Administrator PowerShell, .NET-based Invoke-RestMethod.

Download installer

Same caveats as Linux: use deploy/sensors/install-sensor.ps1 when you need token + URL automation.

One-liner (elevated PowerShell) 
iwr '{{ manager_url }}/sensors/install/windows.ps1' -UseBasicParsing | iex

macos macOS endpoint

The macOS sensor (LaunchDaemon-based) is not yet released. The manager-side schema and policy already support it — an installer ships with a future release.

What the installer does

  1. POSTs to /api/sensors/enroll with the enrollment token, hostname, OS, and platform.
  2. Receives a per-sensor token + sensor ID and stores them in a protected config file.
  3. Installs a small heartbeat agent that POSTs basic inventory to /api/sensors/{id}/heartbeat on a fixed interval.
  4. Registers the agent as a system service (systemd unit on Linux, scheduled task on Windows).

The heartbeat agent in v0.1 reports hostname, kernel/OS, and basic identity only. Full collectors (FIM, processes, listening ports, log shipping) ship with the forthcoming sensor agent build.
