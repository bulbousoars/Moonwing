Compose setup

Moonwing only sees the host where you mount host bin directories read-only. Install tools on the host (SSH), not inside the API image. 

moonwing-api:
  volumes:
    - /usr/local/bin:/host-probe/usr/local/bin:ro
    - /usr/bin:/host-probe/usr/bin:ro
    - /bin:/host-probe/bin:ro
  environment:
    MOONWING_HOST_CLI_SCAN_DIRS: /host-probe/usr/local/bin,/host-probe/usr/bin,/host-probe/bin

For user-local installs, also mount e.g. /home/you/.local/bin:/host-probe/home/you/.local/bin:ro and add that path to MOONWING_HOST_CLI_SCAN_DIRS.
