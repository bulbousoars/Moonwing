macos macOS endpoint

The macOS sensor (LaunchDaemon-based) is not yet released. The manager-side schema and policy already support it — an installer ships with a future release.

What the installer does

  1. POSTs to /api/sensors/enroll with the enrollment token, hostname, OS, and platform.
  2. Receives a per-sensor token + sensor ID and stores them in a protected config file.
  3. Installs a small heartbeat agent that POSTs basic inventory to /api/sensors/{id}/heartbeat on a fixed interval.
  4. Registers the agent as a system service (systemd unit on Linux, scheduled task on Windows).

The heartbeat agent in v0.1 reports hostname, kernel/OS, and basic identity only. Full collectors (FIM, processes, listening ports, log shipping) ship with the forthcoming sensor agent build.
